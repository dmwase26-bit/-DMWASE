# Momentum & Co Marketing Agency Website

A responsive static marketing agency website with service positioning, credibility metrics, trust-video cards, and a booking request form.

## Files

- `index.html` — page structure, copy, trust videos, and booking form.
- `styles.css` — responsive visual design and layout system.
- `script.js` — mobile navigation, trust-video modal, and booking form confirmation behavior.

## Run locally

```bash
python3 -m http.server 4173
```

Then open <http://127.0.0.1:4173/>.
